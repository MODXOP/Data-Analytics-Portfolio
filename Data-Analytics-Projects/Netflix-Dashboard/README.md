\# Netflix Movies \& TV Shows Analytics Dashboard



\## Overview



Created an interactive analytics dashboard to analyze Netflix content trends using Google Sheets.



\## Features



\* Movies vs TV Shows distribution

\* Country-wise content analysis

\* KPI cards for total titles and categories

\* Trend analysis and visualization

\* Google Sheets

\* Pivot Tables

\* Business Analytics
